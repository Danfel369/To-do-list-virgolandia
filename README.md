# To-do-list-virgolandia
Producto Mínimo viable: 

A continuación se define los estándares básicos del proyecto (Esto no fue agregado por Jaeger): (Alopecia)

El To-Do List Virgolandia contará con 3 roles: 

    1- empleado 
    2- líder 
    3- sublíder

De los cuales los requerimientos son: 

Como empleado individual quiero crear tareas para guardarlas, editarlas o eliminarlas y tener un recordatorio para la fecha limite (anotar los deberes del día)

Como lider quiero crear equipos, asignar tareas personalizadas a otros empleados y asignar sublíderes en caso de distintas áreas de trabajo, peticiones a lideres para ser sublíderes de un equipo 

Como empleado quiero agregar categorías de tareas y filtrarlas por categorías

# Sección mi perfil contará con:

Login: correo y contraseña 
Register: nombre de cuenta / correo / contraseña 

Editar perfil: contraseña / foto de perfil / cambiar correo
